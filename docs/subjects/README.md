# Документация по предметам

В этой папке — отдельные подпапки по предметам.

Рекомендуемый состав для каждого предмета:
- `prompts.md` — шаблоны промптов/инструкций к генерации
- `rubrics.md` — критерии качества (что обязательно должно быть в плане)
- `examples/` — хорошие примеры планов/заданий
- `notes.md` — методические заметки
