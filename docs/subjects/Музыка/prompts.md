# Подсказки для предмета «Музыка»

Ниже — набор готовых промптов, примеров активностей и рубрик оценивания, которые можно
использовать для быстрого создания плана урока с помощью ИИ. Скопируйте нужный промпт в
интерфейс генерации и при необходимости подставьте параметры (класс, тема, уровень).

## Короткий промпт (быстрая генерация)

Сгенерируй подробный план урока по предмету "Музыка" для {grade} класса по теме "{topic}".
Укажи цели, оборудование, ход урока с таймингом (45 минут), 3 задания по уровням сложности,
и домашнее задание. Формат — Markdown с заголовками `##`.

## Развернутый промпт (рекомендую для качественного результата)

СОЗДАЙ ДЕТАЛЬНЫЙ ПЛАН УРОКА ПО МУЗЫКЕ

ПРЕДМЕТ: Музыка
КЛАСС: {grade}
ТЕМА: {topic}
ВРЕМЯ: 45 минут

ТРЕБОВАНИЯ:
- Дай чёткие учебные цели (предметные и метапредметные).
- Опиши материалы и оборудование (аудиозаписи, ноты, музыкальные инструменты).
- Приведи подробный ход урока с таймингом и распределением ролей (учитель/ученики).
- Включи 3 уровня заданий (для слабых/средних/сильных учащихся).
- Придумай 2 активности на развитие слуха (listening) и 2 — на исполнение (sing/play).
- Предложи критерии оценивания для практической части и рубрику для 5-бальной шкалы.

Формат результата: Markdown. Будь конкретен, приводи примеры фраз для инструкций ученикам.

## Промпт для контрольной/проверочной работы

Составь короткую формативную проверку по теме "{topic}" для {grade} класса: 5 вопросов (2 — выбор, 2 — краткий ответ, 1 — небольшое практическое задание), укажи правильные ответы и критерии оценки.

## Примеры активностей и упражнений

- Слушание: дать аудиофрагмент (30–60 с) — определить форму/инструмент/ритм; обсудить в парах.
- Исполнение: разобрать простую мелодию, разучить в нотах/по слуху и исполнить в малых группах.
- Ритмическая игра: разделить класс на группы, каждая повторяет ритмический паттерн.
- Композиция: в парах составить короткую фразовую тему (4 такта), добавить простую ритмическую аккомпанемент.

## Рубрика оценивания — практическая часть (пример для 5 баллов)

- 5 баллов — точное исполнение мелодии, стабильный темп, правильная интонация, работа в группе — полноценная.
- 4 балла — небольшие неточности, но понятная структура и участие в ансамбле.
- 3 балла — заметные погрешности в интонации/ритме, но выполняется основная идея.
- 2 балла — участник затрудняется, требует постоянной помощи.
- 1 балл — не выполняет задание или мешает группе.

## Быстрые подсказки для учителя (шерпа-подсказки)

- Если нет инструментов — предложи сольную/вокальную версию и ритмическое сопровождение ладонями.
- Для смешанного уровня предложи ролии: лид-исполнитель (сложнее), аккомпанирующие (средний), слушатели/оценщики (легче).
- Для дистанционных уроков — подготовь 2 аудиофайла: образец и минус-партия; ученики присылают записи.
