# Календарно-тематическое планирование — Математика

Шаблон для календарно‑тематического планирования. Заполните таблицу для учебного года.

## Инструкция
- Укажите темы по порядку и примерное количество часов/уроков.
- Добавьте указания по ресурсам и целям для каждой темы.

## Пример формата
| Период | Тема | Кол-во уроков | Цели | Ресурсы/материалы |
|---|---|---:|---|---|
| Сентябрь (1–4 нед.) | Натуральные числа: деление | 6 | Понять алгоритм деления, практические задания | Учебник, презентация, карточки |

## Примечания
- Можно разбить на микро‑темы по неделям.
- Добавляйте ссылки на материалы из `materials/`.
